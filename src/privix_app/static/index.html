Deterministic Policy Ruleset (Fail-Closed)
Server-Enforced

The Privix Gateway intercepts all 24 browser-use tool actions via an overridden Tools.act() hook before actions can reach the Playwright DOM or network. Policies are deterministic and run locally without cloud dependency.

Public Web Navigation ALLOW

Standard HTTP and HTTPS scheme navigations to public endpoints are permitted without interception.

navigate search go_back http:// https://
Sensitive Form Submission REQUIRE APPROVAL

Submitting form data or clicking form submission triggers requires explicit human verification via cryptographic token.

click [submit] submit_form btn-submit
Sensitive Data Transmission BLOCK

Payloads containing detected SSNs, credit cards, credentials, API keys, or healthcare diagnosis keywords are blocked from transmission.

input send_keys SSN: \d{3}-\d{2}-\d{4} PCI-DSS
Destructive Element Interaction REQUIRE APPROVAL

Clicking buttons or typing commands containing destructive terms (delete, drop table, rm -rf, purge) requires human review.

delete destroy purge drop table
In-Browser Script Execution CRITICAL RISK

Arbitrary JavaScript execution via the evaluate action is classified as critical risk and held for approval.

evaluate document.write eval()
Unknown / Unclassified Actions FAIL-CLOSED

Any unrecognized browser action defaults strictly to BLOCK. Security is never compromised for convenience.

default-deny fail-closed
